# Checklists

## Claim-to-evidence table (keep while drafting)

| # | Claim (as worded in abstract/intro/conclusion) | Where stated | Evidence (section, figure, table) | Source file | Number checked? | Caveat needed? |
|---|---|---|---|---|---|---|
| 1 | | | | | | |

Every contribution bullet and every number in the abstract gets a row. A claim with no evidence row is cut or turned into a stated limitation or future work.

## Pre-submission checklist

Idea and structure
- [ ] The main idea fits in one sentence, and the paper states it.
- [ ] Page one contains the problem with a concrete example, scoped as a molehill.
- [ ] Contributions are bulleted, refutable, and forward-referenced.
- [ ] There is no "rest of this paper is organized as follows" paragraph.
- [ ] Every section supports a contribution, or has been cut.

Body
- [ ] Technical sections lead with an example and the intuition.
- [ ] No narrated dead ends, apart from an obvious approach that the reader needs to see fail.
- [ ] Methods pass the competent-stranger test.
- [ ] Figures pass references/figures.md.
- [ ] Nulls and negatives are reported.
- [ ] The discussion has all four moves: finding with numbers, literature, limitations, next steps.
- [ ] Related work: generous credit, honest trade-offs, no missing close neighbour.

Front matter
- [ ] The conclusion is short, adds nothing new, and does not copy the abstract.
- [ ] The abstract was assembled from paper sentences and includes the key number and its boundary.
- [ ] The title states the finding, includes keywords, and has no hype or question.

Evidence integrity
- [ ] Every number matches its source file.
- [ ] No comparison across different protocols is presented as like for like.
- [ ] Small samples are flagged where claims depend on them.
- [ ] Interpretation is labelled as interpretation.
- [ ] No invented citations. All [CITE: ...] placeholders are listed for the person.

Prose
- [ ] The humanizer pass is done, and facts, numbers, and citations were diffed afterwards.
- [ ] No hype words, few acronyms, terms used consistently.
- [ ] The cold-reader test is done and the "lost here" points are fixed.
